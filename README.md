# Qazaq Air Roblox

Одностраничный сайт сообщества с авторизацией по email, базой Firebase Realtime Database, открытой записью на рейсы, профилями и административной панелью. Интерфейс адаптирован для телефона и компьютера.

## Подключённый Firebase

- Проект: `qazaq-air-roblox-staff` (бесплатный план Spark).
- Realtime Database: регион `europe-west1` (Бельгия), адрес задан в `firebase-config.js`.
- Firebase Authentication: включён провайдер Email/Password.
- Правила базы хранятся в `firebase.rules.json`; участники получают доступ согласно статусу профиля.
- Панель администратора содержит вкладки рейсов, посещаемости, сотрудников, дисциплины, админ-доступа и Google Sheets. Созданный рейс сразу появляется в списке посещаемости; отметки и добавленный экипаж записываются в `flights/<рейс>/attendance`.
- Веб-приложение зарегистрировано как `Qazaq Air Staff Portal`.

## Запуск

1. Создай проект на [Firebase Console](https://console.firebase.google.com/) и веб-приложение.
2. В Authentication включи провайдер **Email/Password**.
3. Создай **Realtime Database**. Установи актуальные правила из `firebase.rules.json` на странице Realtime Database → Rules. Для посещаемости правило `flights/$flightId/attendance/$entryId` разрешает запись только администраторам.
4. Конфигурация текущего веб-приложения уже находится в `firebase-config.js` и подключена из `index.html`. Для другого Firebase-проекта можно заменить её значениями из Firebase Console → Project settings → Your apps.

5. Запусти сайт через локальный статический сервер либо размести его на GitHub Pages. Открытие `index.html` напрямую может не работать с конфигурационным скриптом в некоторых браузерах.

## Первый администратор

Сначала зарегистрируй свой аккаунт. В Firebase Console открой Authentication → Users, скопируй UID аккаунта. В Realtime Database → Data добавь запись:

```json
{
  "admins": {
    "ВСТАВЬ_UID": true
  }
}
```

Первого администратора нужно назначить в Firebase Console: создай аккаунт на сайте, скопируй его UID из Authentication → Users, затем в Realtime Database → Data установи `admins/UID = true`. После этого администратор может выдавать и отзывать доступ в разделе «Выдать или отозвать админ-доступ». Пользователи с должностью «Хост», «Фаундер» или «IT» получают полный доступ к админ-панели, включая управление составом, админ-доступом, одобрением участников, выговорами, предупреждениями и рейсами. Администратор может назначить участнику до двух должностей в разделе «Участники и должности». Для Firebase в качестве основной роли сохраняется Хост, Фаундер или IT, если назначена одна из них. Сотрудник подаёт заявку на рейс с именем, фамилией и должностями из профиля; одобрять её может только администратор.

Участник может изменить отображаемое имя и эмодзи-аватар в своём профиле. Новые аккаунты автоматически получают статус «Допущен» и видят расписание. Должность при регистрации не выбирается: её назначает администратор.

## Google Sheets (по желанию)

1. Создай Google Sheet и открой **Расширения → Apps Script**.
2. Скопируй содержимое `apps-script.gs` в редактор. В `SHEET_ID` укажи часть адреса таблицы между `/d/` и `/edit`.
3. Выбери **Deploy → New deployment → Web app**. Выполнять от имени: **Me**. Доступ: **Anyone**. Разверни и скопируй адрес Web App, заканчивающийся на `/exec`.
4. В `firebase-config.js` укажи адрес в `window.QAZAQ_SHEETS_WEB_APP_URL`.

В таблицу записываются события регистрации, записи на рейс, создания рейса, изменения должности и дисциплинарных записей. URL Apps Script доступен в клиентском коде; таблица не должна содержать секретных данных. Google Apps Script принимает записи без проверки Firebase-токена, поэтому URL следует использовать только для журнала сообщества.

## Публикация на GitHub Pages

Загрузи файлы сайта в GitHub-репозиторий, добавь `firebase-config.js` (он содержит публичную конфигурацию веб-приложения, но не пароль администратора), затем в Settings → Pages выбери ветку и корневую папку. Настрой домен Pages в Authentication → Settings → Authorized domains Firebase. Не добавляй пароли, приватные ключи сервисных аккаунтов или секреты в клиентские файлы.

Название и графика на странице являются оформлением сообщества Qazaq Air Roblox. Для официальных брендовых активов используй только файлы, на которые у сообщества есть права.
